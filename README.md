# RLES 2v2

A competitive 2v2 gaming website with a branded home page and login flow.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view the site.

## Pages

- **/** — Home page with logo, tagline, and call-to-action
- **/login** — Login form (UI only; backend not connected yet)

## Tech Stack

- [Vite](https://vite.dev/) + [React](https://react.dev/)
- [React Router](https://reactrouter.com/) for client-side routing
